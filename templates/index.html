The password used to encrypt the backup. You will need this password to restore from your backups, so make sure to keep it safe.

Retention policy

After each successful backup, old snapshots are expired using restic's forget policy. A snapshot is kept if it matches any rule below. Leave a field at 0 to disable that tier. If every field is 0, nothing is expired (all snapshots are kept). The space freed by expired snapshots is reclaimed by a prune that runs in the background afterwards.

Examples:

  • Local filesystem: /data/app_data/backup/restic-repo
  • AWS S3: URL: s3:s3.us-west-2.amazonaws.com/bucket/, env vars: AWS_ACCESS_KEY_ID=...;AWS_SECRET_ACCESS_KEY=...

Changing the URL does not migrate existing data.

Migrate apps to another instance

Move apps and data to another Cloud in a Bottle instance. The backup app needs to be installed on both instances. An API token from the destination also needs to be provided. This transfers all permanent app data and will restart the app on the other side.

Details about migration
This instance: The selected apps are stopped before the transfer and are left stopped afterward, so nothing writes to their data while it is copied. No data on this instance is modified or deleted.

Destination: Running apps will be stopped during the migration, and existing app data for migrated apps will be deleted. Other apps retain data and are restarted afterward.

Not migrated: API tokens, owner password, and settings are not transferred. {% for entry in scope.excluded if entry.user_facing and entry.reason %} The path {{ entry.path }} is also excluded from the snapshot pipeline. {{ entry.reason }} {% endfor %} See the Backups tab for the full list.
